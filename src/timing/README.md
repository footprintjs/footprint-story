# timing/ — how a purposeful move spends its time

**Why:** a hand reaching for a thing (`footprint-story/human`) and a camera flying between two shots
(`footprint-story/shot`) both start and stop as a purposeful move does: one smooth bell of speed, the minimum-jerk law
(Flash & Hogan 1985). Two copies could drift apart, so the law lives here once, in a file that imports nothing; both doors
reach it and test/doors.test.js allows exactly those two. The human door hands it out (`minJerk`, `minJerkSpeed`,
`minJerkAccel`, `MIN_JERK_PEAK`), one door per name. Its source is in src/human/REFERENCES.md.

|---|---|
| `minJerk.js` | 10u³ − 15u⁴ + 6u⁵, its speed and its acceleration |
